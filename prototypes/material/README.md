# На льду — Material-прототип

Изолированный прототип для согласования интерфейса. Четыре страницы: расписание, матч, команда и таблица. Тёмные нейтральные поверхности и красные акценты; базовые элементы и доступные выпадающие списки — Fluent UI v9.

## Запуск

Нужен Node.js 24. Из корня репозитория:

```sh
npm ci
npm --prefix prototypes/material ci
npm --prefix prototypes/material run dev
```

Открыть http://127.0.0.1:5189/ (сервер слушает только loopback). Изменения автоматически обновляют страницу. В отличие от основного приложения, прототипу не нужны база данных, Cloudflare Worker или переменные окружения.

## Проверка

```sh
npm --prefix prototypes/material test
npm --prefix prototypes/material run build
```

Сборка создаёт обычный статический сайт в .dev/ для HTTP-раздачи. Это не автономный HTML для file://. Инструменты esbuild и tsx доступны через dev-зависимости корневого проекта. Для компонентов установлены отдельные зависимости в этом каталоге; зависимости основного приложения не меняются.

## Что можно посмотреть

- /#schedule — лента дат, фильтр команды и LIVE, загрузка следующих игровых дней.
- /#/team/71 — ближайший матч, последние результаты с соперниками, соседние команды в таблице, статистика сезона.
- /#/standings — общий зачёт, конференции и дивизионы, сортировка, горизонтальная прокрутка на телефоне.
- /#/match/9700242 — отдельная страница матча без drawer/pop-up.

Кошка гоняет шайбу по видимой области, отвлекается на курсор и реагирует на поглаживание. Шайбу можно подтолкнуть курсором-клюшкой. В меню «Кошка» — выключение и ручная демонстрация реакции на гол. Демонстрация не меняет счёт; реальное событие гола не подключено. На touch-экранах нет погони за курсором; prefers-reduced-motion отключает автоматическое движение.

## Данные и границы

Данные в demo-data.ts демонстрационные. Результаты и расписание не являются прямой трансляцией и не согласованы с реальными изменениями таблицы. Эмблемы встроены локально из использованного при проектировании снимка сайта КХЛ; это обозначения клубов, не авторские иллюстрации проекта. Внешних запросов данных и аналитики в прототипе нет.

В основном приложении ничего не подключено. Корневые настройки TypeScript и ESLint исключают изолированный каталог прототипов из проверок Next.js. Реализация намеренно остаётся прототипом; перенос в основное приложение — отдельная работа после утверждения.
